# Independent chronology anchors

`repository_creation.csv` contains selected GitHub API `created_at` timestamps (UTC), observed during the October 20, 2026 inventory. These are **repository creation events**, not the dates on which ideas were conceived or mathematical claims established. Each entry includes the underlying repository API URL.

Later additions should separately record:

- primary-source model release **announcement date** vs **actual user availability**;
- any authenticated conversation/message timestamp or model identifier;
- account notices (with private details withheld) and their exact attribution limits;
- public incident *event date* vs reporting/publication date.

External chronologies should not be constructed by guessing a model from an assistant reply's writing style. The July concentration motivates inquiry, not a causal model of global training or deployment.
